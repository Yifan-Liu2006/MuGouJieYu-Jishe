# 木构解语 —— 应县木塔三维交互式结构分析与工艺科普平台

## 项目简介
木构解语·——应县木塔三维交互式结构分析与工艺科普平台，是一款面向文化遗产数字化保护与大众科普的轻量化沉浸式交互平台。

项目以世界现存最高、最古老的纯木构塔式建筑——应县木塔为核心对象，融合三维可视化、力学动态模拟、传统工艺数字复原、AI智能问答等技术，完整实现建筑3D还原、结构拆解展示、力学科学分析、传统装饰工艺鉴赏、智能科普问答五大核心功能。

平台采用中式古风与现代交互结合的设计风格，以学术级权威数据为支撑，通过低门槛、免部署、跨终端的轻量化架构，打破时空与专业壁垒，让千年木构建筑的营造智慧、抗震机理、艺术美学得以直观呈现、沉浸式体验与高效传播。

项目兼具文化价值、教育意义与技术创新，既可作为文博展示、课堂教学的数字工具，也为古建筑数字化保护与传播提供可复制、可推广的实践范式。

## 🛠️ 本地部署

### 1. 环境准备
下载并安装 **Node.js**（推荐 `20.x` 版本）、项目代码依赖包 **npm** ；准备好项目源码文件夹。

### 2. 部署步骤
1. 打开项目根目录，在文件夹地址栏输入 `cmd`，打开命令窗口；
2. 输入 `npm install` 并回车，安装项目依赖包（等待执行完成）；
3. 输入 `npm run dev` 启动项目；
4. 出现本地地址即启动成功；复制浏览器地址，打开即可使用平台全部功能；
5. 关闭项目：在命令窗口按 `Ctrl + C`，输入 `y` 回车即可停止运行。

### 3. 注意事项
- 必须安装 Node.js 才能启动项目；
- 依赖安装只需执行一次，下次可直接启动；
- 推荐使用 **Chrome / Edge** 浏览器，体验更流畅。

## 📖 项目使用说明
1. 打开平台即可在首页浏览木塔简介、历史时间线、建筑参数、抗震知识，点击按钮进入对应模块。
2. 3D模型支持鼠标拖拽旋转、右键平移、滚轮缩放，悬停构件高亮、点击查看详情。
3. 可依次使用结构拆解、力学模拟、装饰工艺鉴赏功能，支持资料下载与动画演示。
4. 第一视角漫游可选择楼层，按指引操作，沉浸式体验「明五暗四」结构。
5. 右下角 AI 助手可随时提问，仅解答应县木塔与古建筑相关专业问题。
6. 平台支持电脑、手机访问，推荐使用 Chrome/Edge 浏览器，加载稍慢请耐心等待。
