# 应县木塔数据来源说明

## 结构数据
- 柱高、直径、数量：来自《应县木塔结构现状与受力分析》（建筑结构，2015）
- 斗拱种类、数量：来自《应县木塔斗拱形制研究》（古建园林技术，2018）

## 力学数据
- 应力、位移数据：来自《应县木塔静力弹塑性分析》（工程力学，2016）
- 抗震数据：来自《应县木塔结构的抗震性能分析》（建筑结构学报，2017）
- 抗风数据：来自《应县木塔风振响应分析》（土木工程学报，2018）

## 装饰工艺数据
- 彩绘、木雕：来自《应县木塔彩绘与木雕艺术研究》（山西古建筑研究所，2019）
- 匾额、造像：来自《应县木塔匾额与造像考》（文物出版社，2010）

## 平台声明
本平台所有力学数据均来自核心期刊的实测与有限元分析成果，保证了力学可视化的真实性与专业性。
